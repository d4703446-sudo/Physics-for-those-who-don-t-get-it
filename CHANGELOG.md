## [1.0.0] — 2026-10-29

Первый публичный релиз.

### Добавлено
- Справочник по физике 7–11 класс: 19 разделов, ~120 формул.
- Отображение формул через KaTeX.
- Интерактивные калькуляторы: подставляешь числа — сразу результат.
- Лаборатория: бросок под углом (с выбором планеты), распределение Максвелла, ход лучей в линзе.
- Избранное (⭐) с сохранением в `localStorage`.
- PDF-шпаргалка: печать только избранных формул.
- Режим тренировки: формулы размыты, вспоминаешь сам.
- Умный поиск: открытие по клавише `/`, замена «ё» → «е», подсветка совпадений.
- Фильтры по классу и уровню сложности (базовый / углублённый).
- Прямые ссылки на отдельные формулы (anchor-ссылки).
- Тёмная и светлая темы с сохранением выбора.
- Адаптивная вёрстка (телефон / планшет / десктоп).
- README с описанием проекта и LICENSE.

### Технические детали
- Один самодостаточный `index.html` — без сборки и зависимостей, кроме CDN KaTeX.
- Не требует интернета для работы после первой загрузки (кроме шрифтов KaTeX).
